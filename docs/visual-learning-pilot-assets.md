# Diji-Medu Öğrenme Yolu — özgün görsel pilot dosyaları

Tarih: 2026-11-03

Bu değişiklikteki `ingilizce/learning-assets/visual-pilot/` altında yer alan altı SVG dosyası (house, school, flat, garden, park, shop) Diji-Medu için bu çalışma sırasında basit geometrik vektör şekiller ve renkler kullanılarak özgün olarak yazılmıştır. Harici görsel stokundan veya üçüncü taraf görselden kopyalanmamıştır.

Dosyalar istemciye statik olarak sunulur; Supabase Storage, görsel üretim API'si veya yeni bir backend çağrısı gerektirmez. Mevcut iki WebP atlasının telif/kaynak kayıtları değiştirilmemiştir. Bu belge hukuki lisans garantisi değildir.
